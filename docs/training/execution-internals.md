## 一次训练更新

```text
加载与准备底模 → 安装适配器/选择参数 → 安装执行策略
                                            ↓
读取 microbatch → 前向与损失 → 反向与累积 → 优化器更新
                                            ↓
                            按周期保存 → 预览 → 下一次更新
```

执行策略按模型注册的原生区域安装，保留参数身份、权重键名与优化器持有的存储。模型特有的位置编码、时间单位、条件布局和预测公式属于模型实现。

## 编译与重算边界

`compile = false` 使用 eager；`true` 要求 CUDA Inductor，`"auto"` 在 CUDA 启用、CPU 保持 eager。编译只作用于训练模式且开启梯度的块计算；预览和独立生成使用原生评估路径。

权重预取、显存页申请和资源释放在块编译边界外完成。编译可能改变浮点舍入，不保证与 eager 逐位一致。计算精度的配置入口与默认值见[精度](precision.md)。

`recompute = "block"` 使用非重入重算，保留重放所需的 CPU/CUDA 随机状态。Resident 可以按 `recompute_interval` 选择部分块；H2D/VBAR 冻结块策略要求每块重算，间隔必须为 1。没有独立 FFN 重算配置。

## 冻结权重的所有权

冻结权重不求自身梯度，但反向计算输入梯度仍可能读取它们。一次前向取得的权重存储必须保持有效，直到该计算图完成最后读取。

| 对象 | 职责 |
| --- | --- |
| CPU 源权重 | 提供不可变的权重内容，安装期间不允许修改 |
| 权重 lease | 将具体存储的有效期绑定到前向/反向读取 |
| 预取器 | 在独立 copy stream 提前准备允许范围内的后续块 |
| H2D 缓存 / VBAR arena | 管理普通 CUDA 存储或映射页的驻留 |
| 安装器 | 挂接原生块执行，并在反向结束后恢复资源和调用方法 |

适配器、可训练参数及块外需要的模型部分仍位于计算设备。权重卸载不是整模型卸载，也不管理全部激活和优化器状态。

## H2D 缓存

`frozen-blocks` 将连续、同 dtype 的冻结参数组织成 CPU payload。计算使用保持原形状的 view；非连续参数保留 stride 并单独处理。预取与计算通过 CUDA stream/event 协调，活跃 lease 的存储不能被回收或覆写。

省略 `frozen_weight_cache_mb` 时，容量根据实际反向峰值、可用显存及临时转换空间校准。显式值限制保留预算，另计一个当前块工作区；`0` 保留单块工作空间。该预算不是整个训练进程的显存上限。

容量不足以常驻全部权重时，缓存保留选定完整区域，其他区域按需载入和淘汰。显存容量变化会重新规划；活跃图的读取优先于预算。更大且尚未运行的 bucket 仍可能需要降低数据尺寸。

## VBAR 映射权重

VBAR 通过 AIMDO 管理虚拟地址与物理显存页。安装时保留不可变 CPU 源，按需将内容暂存并传输到设备；物理页不可用时使用受保护的回退存储。页 pin 与回退存储同样受权重 lease 生命周期约束。

`unitunner train` 在导入 Torch 前初始化分配器。训练结束时，先完成未结束的设备工作和反向读取，再释放映射、暂存和安装器。不能用推理中前向结束的时机替代训练反向的最后读取时机。

H2D 与 VBAR 是用户选择的两种驻留策略，不会自动互相切换。两者支持 CUDA 冻结底模适配器训练；可训练块交换不受支持。

## 注意力激活卸载

`attention_activation_offload` 通过 saved-tensor hooks 暂存 SDPA 保存的 CUDA 非叶激活，保留形状与 stride。反向读取时复制回设备。它与权重卸载管理不同对象，可在支持的组合内共同使用。

块重算的重放阶段避免再次保留同一组卸载激活。训练仍需要可微分的注意力路径；推理专用 INT8 注意力不能直接用于训练输入梯度。

## 安装和关闭

`TrainingSession` 在构造成功后立即登记资源，并在结束或异常时逆序关闭。`ForwardOverride` 统一检查和恢复实例 `forward` 的所有权：后安装者先关闭，重复关闭无副作用，原来没有实例覆盖时恢复类方法查找。

编译、重算和适配器不在运行时扫描并猜测其他包装器。冻结权重安装器先检查关闭顺序，再清理传输/计算图资源，恢复原设备并释放所拥有的 forward。

续训状态必须在更新完成且梯度清理后保存。`frozen-reference` 可以省去冻结底模副本，但恢复必须使用完全一致的源权重。详见[保存与恢复](README.md#保存与恢复)。
